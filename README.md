## Title

**Personalized Smartphone Notifications Bias Auditory Salience Across Processing Stages**

**Authors:**
Prakash Mishra, Tapan K. Gandhi, and Saurabh R. Gandhi


---

## Overview

This repository contains the codebase and resources associated with the research study *“Personalized Smartphone Notifications Bias Auditory Salience Across Processing Stages.”*


The project investigates how personalized smartphone notifications influence auditory salience and how this bias manifests across different stages of cognitive processing.

---

## Contribution Note
