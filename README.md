## Setting up the subject

1. Clean the subject's head scalp with Ethanol and cotton.
2. Measure the head size and put on head cap identifing the Cz loaction.
3. Put the gel and fix electorde one by one.
4. Check the impedance and reduce it if required with gel.
5. Put on the emotibit on the hand.
6. Ask subject to silent or switch off the phone and put it out side the room. 
Tell subject to be relax and try to talk to subject and make them comfortable. 
7. Tell subject to see the video and enjoy it. Try to avoid the samtphone notification sounds.

## Setting up the experiment

### Things to test / confirm / check
1. Check the EEG impedance and signal quality.
2. Start recording and saving the EEG file.
3. Check Emotibit, data acquisition system and presentation system is in the same network.
4. Start recarding the Emotibit data.
5. file naming convention is subject ID. (all are small letter).
6. Run the Experiment Code.     


## After starting the experiment


### Things to monitor

2. Monitor the Emotibit signal and report if it stop.
